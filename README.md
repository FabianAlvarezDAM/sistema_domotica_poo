Aplicación desarrollada en Python que simula un sistema de domótica gestionado por un Hub central.

El proyecto utiliza Programación Orientada a Objetos para representar y controlar diferentes dispositivos:

- Sensores de temperatura.
- Bombillas inteligentes.
- Cerraduras inteligentes.

 # Conceptos utilizados
 
- Clases y objetos.
- Herencia.
- Encapsulación.
- Clase abstracta Dispositivo.
- Polimorfismo.
- Protocols: Medible, Conmutable y Actualizable.
- Métodos estáticos.
- Excepciones propias.
- Listas, diccionarios, bucles y condicionales.
  
# Funcionamiento

El programa crea distintos dispositivos y los registra en un Hub. Posteriormente permite:
- Listar los dispositivos.
- Detectar sus capacidades.
- Leer valores de sensores.
- Encender y apagar dispositivos.
- Bloquear y desbloquear cerraduras.
- Cambiar el brillo de las bombillas.
- Actualizar el firmware.
- Obtener estadísticas por tipo.
- Probar errores de validación, duplicados y búsquedas inexistentes.
